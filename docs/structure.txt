# CONTROL MODULE

SENSOR FUSION (gyro + accel)
    Runs before outer ring
    IN
        IMU readings
    OUT
        Angle on X and Y

P-controller (outer ring, angle)
    AXIS
        X, Y
        (no compass => Z-rotation doesn't have a P-controller)
    IN
        angle target
        angle measure (from sensor fusion)
    OUT
        rate target

PID-controller per axis (inner ring, rate)
    AXIS
        X, Y
        Z (rate target = 0 or constant from state)
    IN
        rate target (from outer ring)
        rate measure (from gyro)
        sat (from state, needed for anti-windup)
    OUT
        command (-1 <= c <= +1)

Mixer
    Runs after inner ring
    IN
        commands (from inner ring + detached collective)
    OUT
        duty cycles (to be persisted)
        sats (to be saved on state)
    In the case of saturation: Priority as follows:
        roll & pitch
        yaw


SYNCRONIZATION
    HTTP server runs in core 0
        On POST, validates the values and writes them on the state
            TODO: Evaluate weather thread safety is a concern based on the values being edited unatomically
    
    Main loop runs in core 1
        Set a timer on a constant frequency that wakes up main task
        Suspend main task

        [Run outer ring]
        Increment a counter
        Based on the counter, evaluate weather to run inner ring (and keep the counter low to avoid BO)
            [Run inner ring]

        Dump state via telemetry

APPLICATION STATE

    flight_mode                 # disarmed, idle, flight
    mixer_max                   # maximum of the produced duty cycle [0, 1]
    collective                  # duty cycle of the collective [0, 1]
    motors
        one_dc
        two_dc
        tree_dc
        four_dc

    For each rotation axis (for example roll):
        roll                    # roll angle
        roll_set                # roll setpoint
        roll_dot                # roll rate
        roll_dot_set            # roll rate setpoint
        roll_dot_prev           # previous roll rate
        roll_dot_i              # roll rate integral
        roll_sat                # roll saturation flag
        roll_com                # roll command
        roll_alpha              # alpha term of the roll derivative LPF
        config
            roll_outer_p_k           # roll outer controller proportional gain
            roll_outer_max           # absolute maximum of the produced rate [°/s]
            roll_inner_p_k           # roll inner controller proportional gain
            roll_inner_i_k           # roll inner controller integral gain
            roll_inner_d_k           # roll inner controller derivative gain
            roll_inner_i_max         # absolute maximum of the roll integral
            roll_inner_d_fc          # FC for the roll derivative LPF [Hz]
            roll_inner_max           # absolute maximum of the produced command [0, 1]

TELEMETRY
    Push on UDP
    Display via Serial Studio Pro
